ml4w setup
Navigation
pwdshow current folder location
cd foldernamego into a folder
cd ..go up one level
cd ../..go up two levels
cd ~jump to home folder from anywhere
cd -go back to last folder (undo)
Zoxide — smart jumping
z namejump to a folder you've visited before
ziinteractive fuzzy search of history
z ..go up a level (same as cd ..)
z ~go home
Gets smarter over time — the more you navigate, the better it knows where you mean
Listing files — eza
lssimple list with icons + colors
lldetailed list with sizes, dates, git status
lttree view, 2 levels deep
lt --level=1tree view, 1 level only
lt --level=3tree view, 3 levels deep
lashow hidden files too (dotfiles)
Reading files — bat
cat file.txtview file with syntax highlighting
catp file.txtplain output, no decorations
cat -n file.txtshow with line numbers
Press q to quit if file is long. Space to scroll down.
Editing — micro
micro file.txtopen a file for editing
micro ~/.bashrcedit your shell config
Ctrl + Ssave
Ctrl + Qquit
Ctrl + Zundo
Ctrl + Ffind / search in file
Creating & managing
mkdir foldernamecreate a new folder
touch file.txtcreate a new empty file
cp file.txt copy.txtcopy a file
cp -r folder/ new/copy a whole folder
mv file.txt ~/Docs/move a file to another folder
mv old.txt new.txtrename a file
Deleting
rm file.txtdelete a file
rm -r foldername/delete a whole folder
⚠ No recycle bin on Linux. Deleted files are gone instantly and permanently. Double-check before running rm.
Searching — ripgrep
rg "word" .search for text in current folder
rg "word" ~/path/search in a specific folder
rg -i "word" .case-insensitive search
ll | grep namefilter file list by name
Great for finding config settings — tells you exactly which file and line number
Packages — pacman
sudo pacman -S nameinstall a package
sudo pacman -R nameremove a package
sudo pacman -Syuupdate everything on your system
pacman -Ss namesearch for a package
yay -S nameinstall an AUR package
Power combos
z hypr && micro hyprland.confjump to folder and open file
cat file && micro filepreview then edit
source ~/.bashrcreload config after editing
Ctrl + Ccancel / stop whatever is running
Ctrl + Lclear the terminal screen
↑ arrow keycycle through previous commands
tip: press ↑ in terminal to recall last command ctrl+c cancels anything · q quits bat pager · tab autocompletes
